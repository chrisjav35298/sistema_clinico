Guía de Renderizado de Formularios en Django

Diferentes formas de renderizar el objeto form en la plantilla.

1. Renderizado Básico: {{ form }}

Muestra los campos en línea de forma directa, sin etiquetas contenedoras (solo <label> e <input>).

{% csrf_token %} {{ form }}
2. En párrafos: {{ form.as_p }}

Envuelve cada pareja etiqueta/campo dentro de un párrafo (<p>).

{% csrf_token %} {{ form.as_p }}
3. En ítems de lista: {{ form.as_ul }}

Renderiza los elementos en tags <li>. Requiere que agregues manualmente las etiquetas <ul>.

{% csrf_token %}
    {{ form.as_ul }}
4. En tabla: {{ form.as_table }}

Renderiza las filas (<tr>) y celdas (<td>). Requiere que agregues manualmente la etiqueta <table>.

{% csrf_token %} {{ form.as_table }}
5. Control Manual Campo por Campo

Ideal para cuando querés armar layouts complejos (por ejemplo, poner nombre y apellido al lado del otro).

{% csrf_token %}
{{ form.nombre.label_tag }} {{ form.nombre }} {{ form.nombre.errors }}
{{ form.email.label_tag }} {{ form.email }} {{ form.email.errors }}
{{ form.mensaje.label_tag }} {{ form.mensaje }} {{ form.mensaje.errors }}
6. Renderizado Dinámico con Bucle: {% for campo in form %}

Itera sobre todos los campos del formulario automáticamente, aplicando una estructura uniforme sin escribirlos uno a uno.

{% csrf_token %} {% for campo in form %}
{{ campo.label_tag }} {{ campo }} {{ campo.errors }} {% if campo.help_text %} {{ campo.help_text }} {% endif %}
{% endfor %}
